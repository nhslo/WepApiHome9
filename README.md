# Домашнее задание 09 — список задач

## Краткий отчёт

Создана консольная программа управления задачами. Данные хранятся в памяти.

## Выполнение по заданию

### 1. Задачи и хранение

Структура `Task` содержит ID, название, описание, приоритет и статус. Интерфейс `TaskStorage` реализован структурой `MemoryStorage`.

### 2. Действия

Через меню можно создать, просмотреть, изменить и удалить задачу, поменять статус, найти задачи по названию, приоритету или статусу и посмотреть статистику.

### 3. Проверка

Проверены создание, редактирование, смена статуса, поиск, удаление и статистика. Одна завершённая задача из одной даёт 100%. Пустое название, неверные приоритет и ID обрабатываются как ошибки.

## Запуск

В PowerShell из этой папки:

```powershell
go run .
```

Выбирайте пункты меню и отвечайте на подсказки. Данные существуют до выхода из программы.

## Вывод

Срез хранит задачи, интерфейс описывает операции, а методы с указателем позволяют изменять данные.
